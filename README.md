# Catalyst Electrobun Boilerplate
Monorepo starter with a Catalyst web app and an Electrobun desktop shell that loads the web app.

## Tech Stack
- Catalyst (`catalyst-core`) for web app
- Electrobun for desktop shell
- React + Tailwind (desktop fallback view)
- Node.js + npm (web)
- Bun (desktop)

## Getting Started (prerequisites + quick-start)
Prerequisites:
- Node.js `20.4.0+`
- npm
- Bun `1.1+`
- macOS, Windows, or Linux

Quick start:
```bash
npm run setup
npm run dev
```

Using this as a template:
```bash
gh repo create <your-new-repo> --template rajavijayach/catalyst-electrobun-boilerplate --public
git clone https://github.com/<your-org-or-user>/<your-new-repo>.git
cd <your-new-repo>
npm run setup
```

Default URLs:
- Web: `http://localhost:3005`
- Desktop fallback dev view: `http://localhost:5173`

## Configuration / Customization
- Override web URL for desktop via `CATALYST_WEB_URL` (default: `http://localhost:3005`).
- Web health endpoint is available at `GET /api/health`.
- Desktop RPC shared types are in `apps/desktop/src/shared/rpc.ts`.
- Desktop main process integration is in `apps/desktop/src/bun/index.ts`.
- Update desktop metadata in `apps/desktop/electrobun.config.ts`:
  - `app.name`
  - `app.identifier`
  - `app.version`
- Rename package metadata if needed:
  - root `package.json` (`name`, `description`)
  - `apps/web/package.json` (`name`, `description`)
  - `apps/desktop/package.json` (`name`, `description`)

## Scripts
Root scripts:
- `npm run setup`: install web + desktop dependencies
- `npm run dev`: run web + desktop together
- `npm run dev:web`: run Catalyst only
- `npm run dev:desktop`: run Electrobun only
- `npm run lint`: web lint + desktop UI build validation
- `npm run build`: build web + desktop
- `npm run build:web`: build Catalyst app
- `npm run build:desktop`: build Electrobun canary artifacts

## Deployment
- Web build output is generated by `npm run build:web` inside `apps/web/build`.
- Desktop artifacts are generated by `npm run build:desktop` from Electrobun.
- CI pipeline (`.github/workflows/ci.yml`) runs lint and desktop UI build validation on push/PR.
